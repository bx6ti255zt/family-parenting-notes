# 预防乳腺癌，要做什么检查？

> 更新时间：2026-09-11 (UTC+8)

乳腺癌，听起来遥不可及，实际上近在咫尺~

如何预防乳腺癌？

郑州市妇幼保健院乳腺科主任韩红勤来给大家讲一讲。

以下人群是乳腺癌的最爱，快看有没有你

•  初潮年龄在12岁前或停经年龄超过55岁

•  晚婚晚育后没有生育

•  多次做过人工流产手术

•  过于肥胖

乳腺癌有哪些症状

主要症状表现为：

• 乳腺肿块

• 乳头溢液

• 乳头改变

• 皮肤改变

• 腋窝淋巴结肿大

有的女性朋友会问乳房疼痛算是主要症状吗？

韩主任介绍：疼痛不能算乳腺癌的主要症状，绝大多数乳腺癌发现时的表现是无疼性乳房肿块，也有病人因为乳房疼痛采取体检进而才发现乳腺癌。患有乳腺增生的患者也会感到乳房疼痛。需要提醒的是有乳房疼痛的患者也要到正规医院体检检查。

乳腺癌的检查方法

看

家里有全身镜的朋友可以对着镜子站好，双手自自然下垂，看看乳房是否大小对称，有没有不正常凸起，皮肤和乳头有无凹陷。

按

左手举到头部后侧，用右手手指轻按乳房，从乳头开始，从内往外做顺时针检查，感觉一下有没有硬块。换手用同样的方法检查右边乳房。

躺

平躺在床上，左肩膀下垫一个枕头，右手放头下，检查两侧乳房。

查

除了检查乳房，还要检查腋下有没有淋巴肿大。用大拇指和食指挤压乳头，观察有无异常分泌物。

光靠自检还不够，还可以去医院做：

•  身体检查

•  乳腺的X线检查

•  超声检查

•  乳腺导管内窥镜

不同年龄段，体检也有所不同：

20~40岁：日常自检

40~49岁：每年体检1次

50~69岁：每1~2年体检1次

70岁以上：每2年体检1次

如果有直系亲属得了乳腺癌或者小叶原生癌，有胸部放疗经历的人，可提前到20岁进行，建议每年一次。

胸大容易得乳腺癌？
有人说：胸大有什么好的，而且容易得乳腺癌。

胸小的妹子看到这里倒吸一口冷气。

**韩主任表示：****目前没有研究表明“胸大”就更容易得乳腺癌。**乳腺癌的风险不应关注乳房是否大小。

脂肪组织才是乳房的主要成分，其次是乳腺腺体组织。而乳腺癌是发生在乳腺腺上皮组织的恶性肿瘤。女生胸大或者胸小，其乳腺腺体组织的数量差别不大，外观大小的区别主要在胸部的脂肪上。

脂肪虽不会癌变，但乳腺癌的风险系数跟脂肪有关，这里说的脂肪并非胸部脂肪，是指体重。有国外研究表明：乳腺癌与肥胖有相关性。

所以说，是A是C不重要，健康的身体才是最重要的。

乳腺癌很可怕，能不能治愈？

不管是谁，得了乳腺癌之后都会难以接受。其实，大多数乳腺癌是可以治愈的。乳腺癌位于体表，用手就可以摸到肿块，目前乳腺癌治疗发展快，疗效也比较好。

早期发现乳腺癌的治愈率达到90%。因为很多女性没有主动进行乳腺检查，所以才给了乳腺癌可乘之机。所以说，做好预防和检查非常重要！

根据乳腺癌的发病机制不同，每个人的治疗方案也不一样。

滚蛋吧，乳腺癌

1、注意饮食，远离高脂、高糖、高热量的食物，多亲近高纤维的食物，保持健康的体重。

2、积极锻炼，每周坚持4次体育锻炼，患乳腺癌的危险减少50%。

3、保持良好的生活习惯，不当“夜猫子”，保证足够的睡眠。

4、避免人工流产。

5、坚持正确的母乳喂养。

6、避免过量吸烟、饮酒。

7、避免过量或长期服用可致癌药物。（安眠药、抗抑郁药、利尿剂）

**韩主任温馨提示**
自检不能替代必要的防癌检查，如果给自己检查的时候怀疑有异常，也不要胡思乱想，去正规医院检查一下就好了。 大多数乳癌发现时的表现是无痛性乳房肿块， 但确有病人因为乳房疼痛去体检进而才发现乳腺癌的，常规去医院进行专科体检必不可少。
