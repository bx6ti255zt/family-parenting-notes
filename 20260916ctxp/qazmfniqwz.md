# “椎体骨水泥”，轻松解决93岁老人的骨折疼痛！

> 更新时间：2026-09-16 (UTC+8)

93岁的赵爷爷平时身板硬朗，喜欢在家种点儿小菜。近日，在弯腰提水后感觉腰部疼痛厉害。原本以为只是一次小的腰拉伤，考虑到高龄，家人决定采用常规保守治疗——卧床休息。可是躺了几天未见好转，反而疼痛症状逐渐加重。于是家人陪同来到市人民医院骨三科就诊，诊断为“骨质疏松椎体压缩性骨折”。

“随着年龄的增长，骨质变得萎缩、疏松。高龄老人弯腰捡东西，或者搬抬重物时，稍有不慎，都可能引起骨折。如果行长期卧床保守治疗，骨折愈合较慢不说，还极有可能出现肺部感染、血栓等并发症，导致比较严重的后果”,值班医生顾翔介绍，结合赵爷爷的病史、体征及影像学检查结果，建议住院行微创”经皮穿刺椎体成形术”。

在进行了常规的检查后，只用了半个多小时就完成了手术。

“做完了就不疼了，这么快就能走路了，医生这技术真厉害！早知道效果这么好，前几天就不在家遭这罪了”术后短短几小时，赵爷爷就下地行走了，他开心地笑着，竖起大拇指连声称赞。

“经皮穿刺椎体成形术”俗称“椎体骨水泥强化术”。骨科三病区主任陈雷介绍，医生通过X线透视定位找出骨折的椎体，只在皮肤上做一个3毫米的小切口，然后用穿刺针通过这个小切口将“骨水泥”注入骨折椎体，以此来增加椎体强度和稳定性，防止塌陷，缓解疼痛，具有“精准、微创、恢复快”等优势，是治疗骨质疏松症的首选方法。

**健 康 科 普**

**骨质疏松症椎体压缩性骨折**是老年人常见疾病之一，提东西、弯腰、轻微地咳嗽等，就可能发生椎体压缩性骨折。因此，老年人要从以下几方面加强预防：

1.一定要做好防滑防摔措施。如确需外出，应有家人陪同，需穿宽松、舒适且透气的衣服，鞋子选择防滑鞋，也可借助适老辅助器械，如拐杖等。

2.调整生活方式，起身、下床、行走速度放慢，避免搬提重物，如厕使用扶手，减少跌倒风险。

3.勤晒太阳，适当锻炼，推荐慢走、八段锦等运动。

4.戒烟、限酒，减少浓茶、咖啡、碳酸饮料的摄入量。

5.合理膳食，加强富含钙和维生素D食物的摄取。最后，如不慎发生摔伤，一定要及时来院就医。
